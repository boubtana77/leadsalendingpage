# LeadSaaS Landing Page

A premium, light-first marketing landing page built with Next.js 14, Tailwind CSS, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Included

- Premium responsive header with Product mega-menu
- Hero with interactive service-aware opportunity mockup
- Old way vs LeadSaaS positioning
- Individual vs Company interactive toggle
- 6-step product workflow
- Evidence → Sales Angle → Outreach visualization
- Prospects / Campaigns / CRM continuity section
- Controlled sender infrastructure section
- Lifecycle tracking
- Tasks & Follow-ups
- Supporting capability grid
- Pricing placeholder without invented pricing
- FAQ
- Final CTA and footer

The copy intentionally avoids unsupported claims such as full mailbox reading, native multichannel sending, full CRM replacement, automatic task creation, unlimited email sending, or cross-device cloud synchronization.
